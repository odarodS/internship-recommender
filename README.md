# Internship Recommender

A small Python tool that recommends internships based on a student's skills.
It compares the student's skills with each internship's requirements,
ranks them by match score, and shows which skills are missing.

> The internship data in this project is fictional, made for demonstration.

## How to run

1. Install Python 3.
2. Run: `python recommender.py`
3. Type your skills separated by commas, like `python, html, excel`.
